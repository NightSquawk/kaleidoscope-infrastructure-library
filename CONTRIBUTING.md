# Contributing

Submit reusable hardware data and original artwork under CC0-1.0; software and documentation under Apache-2.0. By submitting, confirm you have rights to do so and identify any third-party material and its original license.

1. Use stable IDs and factual manufacturer/model labels only for verified models. Mark generic or approximate drawings as illustrative.
2. Keep external definitions unmodified under their source/license folder. Record source commit, source file and checksum. Add visual extensions separately.
3. Do not copy manufacturer imagery without documented redistribution permission. Include required attribution and notices with each asset.
4. Record evidence for chassis dimensions, connector order and module options. Never invent physical port placement from interface names.
5. Register every new file in asset-manifest.json, refresh intended hashes, run validation and tests, regenerate the preview and inspect it.
6. Do not include real customer infrastructure or telemetry.

Use generic fallback artwork while exact layouts are unverified. This starter does not yet provide a graphical template editor or automatic upstream synchronization.
